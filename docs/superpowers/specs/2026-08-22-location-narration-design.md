# 风里的站定位与旁白设计

## 目标

在“风里的站”加入一个用户主动触发的定位入口：取得当前位置后自动切换至距离最近的站点；每个站点可复制正文到豆包等朗读工具。

## 交互

1. 用户点击“定位当前站”。页面请求浏览器定位权限，仅获取一次当前位置。
2. 页面以路书中的站点坐标计算直线距离，切回“全部”筛选并切换至最近站点，同时把“风里的站”滚动到视野内。
3. 状态文案显示最近站名称和距离：只有在距离很近时才写“你在附近”，否则写“离你最近”。定位被拒绝、超时、不支持和无可用坐标均给出可操作的说明。
4. 每个站点的操作区增加“复制正文”。点击后只复制正文的实用段落，不复制标题、时间地点、导语、背景、按钮、导航链接或图片说明；复制成功后提示粘贴到豆包朗读。

## 数据与边界

- 坐标优先从各站现有高德标注链接的 `position=经度,纬度` 中读取；没有标注链接的既有站点用小型内置坐标表补齐。
- 高德坐标与浏览器 GPS 坐标的基准并不完全一致，因此定位功能以“最近站”匹配而非严格电子围栏为准，距离显示为近似值。
- 不持续追踪位置，不上传位置；定位与复制均由用户点击触发。
- 使用浏览器原生 `navigator.geolocation` 与剪贴板 API，不新增依赖、不请求第三方接口；本地文件环境下可回退到浏览器兼容的复制方式。

## 验收

- 给定七彩丹霞附近的坐标，最近站匹配到“七彩丹霞”；空站点列表返回无结果。
- 定位成功时，站点筛选回到“全部”，自动切换且展示距离状态。
- 每站有复制正文控制；成功与失败状态均不会留下错误按钮文字。
- 既有横滑、地区筛选、导航和无障碍操作保持正常。
