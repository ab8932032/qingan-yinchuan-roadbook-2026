# 沿途影像

已经加入 9.24—10.5 共 12 天的短片，每天有横版和竖版。采用关联聊天按天精选中的 54 张照片，以及自行绘制的纸片公路动画。每段约 16–22 秒，配有三组原创合成轻器乐，全部在本机剪辑与编码。

- `films/v2/`：24 个 H.264 + AAC MP4，横版 1280×720、竖版 720×1280，总计约 41 MiB。旧版导出保留在原目录。
- `stills/v2/`：对应横竖版封面，不含原照片 EXIF。
- `scripts/theater-data.js` 的 `dailyFilms`：日期、地点与两个画幅的对应。点未选中的图标只切换地点与短片；再点当前图标打开记录，并暂停影片但保留进度。跨日地点在画面下方只显示相关日期。
- `notes/daily-film-edit.json`：选片清单及来源。手机保存日期独立保留；修图保存日期可能跨日，以画面和口述行程归站，未经确认的景点没有加入。
- `scripts/build_daily_films.py`：只读素材并输出短片。依赖 Pillow、pillow-heif、NumPy、imageio-ffmpeg；本版优先解码最终精选副本的完整图像，失败时才回退已有预览。未更改手机原片和另一聊天的分类结果。

界面加载不会预先下载全部短片。当前播放的影片按需保留完整缓存，再响应播放器的字节范围请求，已缓存影片可离线观看。减少动态效果开启时不自动播放；仍可用原生控制手动观看。

原来按路段的 `acts[].media` 仍可作为未配置每日影片时的后备队列。

## 每段旅程的短片

后续替换或补充的短片可放在 `media/films/`，封面放在 `media/stills/`，在相应路段配置：

```javascript
"media": [
  {
    "type": "video",
    "src": "media/films/helan.mp4",
    "poster": "media/stills/helan-cover.jpg",
    "caption": "9.25 · 贺兰山下"
  }
]
```

## 先排片，后剪成片

可以把照片和视频混排，先在浏览器里检查叙事顺序：

```javascript
"media": [
  {
    "type": "photo",
    "src": "media/stills/courtyard.jpg",
    "duration": 4,
    "caption": "宿集的院子"
  },
  {
    "type": "video",
    "src": "media/films/room-original.mp4",
    "start": 2,
    "end": 8,
    "caption": "下午，在房间里休息"
  }
]
```

- `photo.duration` 是照片停留秒数，默认 4 秒，范围 1–60 秒。
- `video.start/end` 是原视频中的入点与出点；省略时播放完整片段。也可用 `start` 与 `duration` 指定截取长度。
- `caption` 是可选画面说明，按普通文字显示。
- `fit` 默认 `contain`，完整展示横竖幅素材；确需铺满时才设为 `cover`。
- 中央随屏幕方向调整比例，以 `contain` 容纳原画幅。视频默认静音，可通过原生控件开启声音或全屏观看。
- 浏览器排片不会生成新的 MP4；当前每日成片由本地构建脚本导出。后续实拍视频、环境声与音乐可继续剪入，再替换相应队列。
- 尚未提供的素材不写假路径。保持 `media: []` 就会显示纸片风景。

路径以项目根目录为起点，使用 `/`；不要使用电脑绝对盘符路径。照片与视频保留原文件另行备份。当前离线缓存覆盖界面和文字记录；新加入的成片应在接入时单独安排缓存，避免首次打开自动下载大量原始素材。

## 第二版选片与声音

最终每日精选共有 292 张推荐，第一版所用 59 张也都在其中；问题是二次抽片偏记录镜头。第二版重新逐张复核为 54 张，其中 37 张具有编辑标记，旅拍成片优先，并采用完整分辨率。文件标记不等于摄影师来源，选片审计见 `notes/daily-film-selection-audit-v2.json`。

三组配乐由 `scripts/compose_film_music.py` 在本地合成，母带与曲目信息放在 `media/music/`。所有发布的视频均已写入 AAC 音轨，检查结果见 `notes/daily-film-render-v2.json`。播放器记住配乐开关；首次有声自动播放被浏览器限制时，点“开启配乐”即可。
