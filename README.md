# 青甘银川 · 旅行游记

2026 年成都往返银川、河西、敦煌与青海的自驾纪行。主界面是纸片布景围绕中央银幕的小剧场，仍按实际停靠地点组织内容。每个地点集中呈现经历、住宿、吃喝、时间点、原路书故事与补记。沙盘全景作为另一种视角保留。

## 打开

手机在线预览：https://ab8932032.github.io/qingan-yinchuan-roadbook-2026/ 。GitHub Pages 从 `main` 分支根目录发布，`.nojekyll` 保证资源按静态文件提供。当前发布保留现有影片，新的照片选片与替换继续在本机进行。

新剪辑独立预览：https://ab8932032.github.io/qingan-yinchuan-roadbook-2026/preview/v3/ 。也可以直接打开 [沿途影像](https://ab8932032.github.io/qingan-yinchuan-roadbook-2026/preview/v3/films.html) 逐段看。V3 将最新精选与对应 Live 按地点剪成 26 段，提供横竖双版和配乐；主入口继续保留 V2。

直接双击 `index.html` 即可。所有主界面资源都在本地，不需要地图 Key、外部字体或第三方脚本。主界面已整合原路书：对应内容归入地点的“行前存页”，预算、行李、路段等共用内容收入“更多选项 → 随行手册”。完整底稿仍保存在根目录的 `roadbook-original.html`，作为备份。

需要离线缓存或本机浏览器预览时，在此目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

访问 http://127.0.0.1:8765/ 。首次在线打开后，沙盘、地点数据和原路书会保存为离线副本。直接双击的 `file://` 打开方式可以阅读和交互，但不注册 Service Worker。

## 沿途影像

纸片布景只负责视觉氛围，界面使用游记的语言。中央展示当前路段的地点、日期和风景；以后加入实拍照片或短片，会直接在这里显示。没有二次播放入口、章节菜单、预演功能或素材占位提示。

`scripts/theater-data.js` 管理地点与每日影像的对应。`media` 支持照片、视频与混合队列，照片可设时长，视频可设入点、出点。视频使用原生控件，有配乐开关；首次有声自动播放被浏览器限制时，点击“开启配乐”。失败素材自动跳过，均无法打开时回到纸片风景。页面隐藏或阅读记录时暂停，关闭记录后继续。配置格式见 `media/README.md`。

## 阅读方式

- 首次点击地点切换中央影片，再点当前地点，在图标左侧或右侧显示该站记录；空间不足时轻移场景，保留图标和连接线。弹窗内可滚动阅读，点场景空白或按 Escape 收起。
- 地点弹窗分为“这一站 / 行程攻略 / 地方故事 / 行前存页”。实际经历与历史计划各自保留；手册中的地点索引也能直接打开相应存页。
- 手机竖屏采用纵向布景和竖幅银幕，手机横屏采用宽幅舞台，旋转时自动重排；关闭记录后回到舞台。
- “全程地图 / 旅程总览”切换两种视角。
- “行程”列出 19 个主地点与 2 处市内支线，按实际经过顺序排列；城市、景点、住宿和途经点都能选择。
- 拖动移动沙盘，滚轮、双指或加减按钮缩放，“全程”恢复总览。
- “上一站 / 下一站”串起整趟行程，西宁之后回到成都。
- 每个地点有稳定链接，例如 `#place=helan`、`#place=danxia`、`#place=lake`。原来的日期书签和 `#return` 会映射到相应地点。
- 沙盘是行程示意；小剧场的地点围绕银幕按行程序列排布，均不用于导航。

具体的时间安排在“行程攻略”，也可以从“行程 → 按日期”查看全程。实测钟点与时间差、高德驾车参考、未定位的环湖段分别标注；不把含游览、用餐的时间差算作纯驾驶。敦煌作为主地点，沙州夜市、敦煌四局作为两处市内支线；各自的旧书签和补记继续使用。冷湖石油遗址已按用户确认的名称记录。

## 本机补记与备份

- 每个地点的新补记使用 `roadbook-place:<地点ID>:note`，自动存在当前浏览器。
- 原来的 `roadbook-note:<日期ID>:line/timing` 保留原键，按日期在相关地点下读取。同一天有多个地点时，旧补记明确标为“当天”的内容。
- 原有 `qinggan-roadbook-media` IndexedDB 只读，照片和视频按原日期显示。主界面不删除、迁移或重新上传影像。
- 页首“更多选项 → 保存文字”导出所有地点的正文、故事、行前存页与本机文字补记。影像仍保存在原浏览器，文字备份不包含媒体文件。
- 浏览器存储按地址隔离：文件地址与 localhost、不同端口、不同设备的补记并不共用。

## 编辑

修改 `atlas-data.js` 中对应的地点即可补内容；一个地点可以跨日期（例如水上雅丹的住宿与次日游览）。`route` 可以重复出现一个地点，用来表达返回张掖市区、最终回成都等路线。

地标的 `kind` 对应 `index.html` 里的 SVG symbol。维护地图时应同步调整地形与各地点坐标，保持标签可读。坐标是沙盘布局单位，非经纬度。更新资源后调整 Service Worker 缓存版本。

新增文字保留游记语气，轻度润色；不堆解释性标题，不反复摘抄，不代编对话、心理、光线和消费。以用户实际叙述为准，原计划不证明实际到访或实付。

## 检查

```powershell
python -m unittest discover -s tests
node --check scripts/atlas.js
node --check scripts/atlas-data.js
node --check service-worker.js
```

早期完整底稿与旧内容测试另存于 `docs/archive/`。新结构不再沿用按功能分区的页面测试，保留文案检查器自身的单元测试，并验证地点数据、离线资源与旧记录兼容性。

主界面、地点记录和手册可离线使用；影片按需缓存，并支持手机视频播放需要的字节范围请求，不在首次打开时下载全部影片。

高德参考车程已按现有 JS API 配置查询，查询结果静态保存在数据文件中；主页面不因打开弹窗而重复请求高德。普通城市使用明确标注的市区点，盐湖与雅丹以游客中心为参考，青海湖以二郎剑景区为参考。观星营地存在多个模糊匹配，未将任意候选视为本次实际营地。

地点独立保留，张掖、敦煌与冷湖景点采用地区前缀。俄博梁不再单列，旧书签指向火星营地，原有补记保留可读。道路标注是行程示意；高德默认路线不等同火星一号公路穿越路线。

周边地貌以独立的非交互背景层绘制：腾格里沙漠、贺兰山、祁连山脉、柴达木盆地。按沙盘不同宽高重新排布，均为示意，不添加到到访站点或车程；位置关系与资料来源保存在 atlas-data.js 的 landscapes 字段。

已加入每日短片：9.24—10.5 共 12 段，横竖双版。54 张实拍照片与三段原创纸片公路动画组合，按地点直接在中央播放，已加入轻器乐配乐；跨日地点仅显示相关日期。详细选片与构建方式见 media/README.md。原始手机导出与另一聊天的分类结果保持只读。

图标首次点击只切换地点与影片，再次点击当前地点才展开记录。最终精选重排与有声成片采用 v2 路径，避免浏览器继续使用旧片；选片审计与音轨检查保存在 notes。

V3 使用 `media/films/v3/` 与 `media/stills/v3/` 独立文件。`preview/v3/films.json` 只保存公开标题、地点映射和相对媒体地址；原始照片、Live MOV、定位与本机选片清单不随网站上传。油址、黑独山、火星一号公路、火星营地门口分别剪辑，水上雅丹只采用 10 月 2 日上午素材。暂未确认对应素材的地点保留纸片风景，不借用同日其他地点的影片。
